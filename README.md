## 🌒 Features

### 🔍 Tactical Evidence Filtering

Identify ghosts using a high-contrast, interactive evidence grid. The UI reacts instantly, crossing out impossible entities as you gather data.

### 🌍 Multi-Regional Support

Fully localized for **English** and **French** investigators. Toggle locales instantly via the system tray.

### 🌑 Dark Reader Optimized

Engineered with a custom `zinc-950` and `red-600` palette. Includes anti-inversion measures to ensure the horror atmosphere remains intact even with browser extensions active.

- **Framework:** React 18+ (with TypeScript)

- **Styling:** Tailwind CSS 4 (Oxide Engine)
- **Localization:** i18next

## 🚀 Deployment

This project is configured for **GitHub Actions**. Pushing to the `master` branch triggers an automated build and deploy to GitHub Pages.

You can use the diary [here](https://friquetluca.github.io/phasmophobia_diary/).

### Local Development

1. **Clone the repository:**

   ```bash
   git clone https://github.com/FriquetLuca/phasmophobia_diary.git
   ```

2. **Install dependencies:**
   _Requires Node.js 20.19+_

   ```bash
   npm install
   ```

3. **Ignite the terminal:**
   ```bash
   npm run dev
   ```
